# Kitchen and Service Timer

Royal Flight Club mobile timing observations, adapted from the Civil Aviation Club timer. Five sequential timing checkpoints, monthly summary, searchable observation log, CSV export and JSON backup/restore.

All observations and preferences stay in this browser on this device. No upload endpoint, analytics or cloud synchronization. The public repository includes app code and generic icons only. The Royal Flight Club copy begins with an empty observation log. Keep backups private.

Installable on supported browsers; open online once to cache app files for offline use.
